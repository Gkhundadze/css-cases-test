# CSS Engineering & Architecture Cases (თეორიული ქეის-ტესტი)

> 🎓 **საინჟინრო და თეორიული შემოწმება:** ეს დავალება აჯამებს და პრაქტიკულ ქეისებად გარდაქმნის წინა დავალებებში მიღებულ ცოდნასა და გამოცდილებას

---

## 🎯 მიზანი და ფორმატი

ტრადიციული, მშრალი ტესტებისგან განსხვავებით, ეს ტესტი აგებულია **12 რეალისტურ საინჟინრო ქეისზე** (Real-world Production Cases):
- დეველოპერი აწყდება ბაგს პროდაქშენზე ან DevTools-ში;
- აანალიზებს გაფუჭებულ კოდს, ზომების მათემატიკას ან სელექტორის მახეს;
- პოულობს არა ზედაპირულ პატჩს, არამედ პრობლემის ნამდვილ ძირეულ საინჟინრო მიზეზს (Root Cause).

ტესტი არის **საშუალო სირთულის (Mid-Level)** — არც ელემენტარული და არც ხელოვნურად გადატვირთული.

## 📸 ჩაბარების ინსტრუქცია სტუდენტებისთვის

1. გახსენით `06-css-cases-test/index.html` ნებისმიერ თანამედროვე ბრაუზერში (Chrome, Edge, Firefox, Brave).
2. საწყის ეკრანზე შეიყვანეთ თქვენი **სახელი და გვარი** და **ჯგუფი/ID**.
3. გაიარეთ 12-ვე ქეისი (თითოეულ ქეისზე შეგიძლიათ ისარგებლოთ ღილაკით *„💡 DevTools მინიშნება“*).
4. ტესტის დასრულებისას ავტომატურად დაგენერირდება **ოფიციალური შეფასების ფურცელი (Assessment Certificate)**:
   - თქვენი სახელი და გვარი;
   - ჩაბარების ზუსტი თარიღი და დრო;
   - დახარჯული დრო;
   - მიღებული ქულა და პროცენტი (მაგ. 92% — 11 / 12 ქულა);
   - უნარების პროფილი 5 კატეგორიაში;
   - **ვერიფიკაციის უნიკალური ციფრული კოდი (Verification Hash)** — იცავს შედეგს გაყალბებისგან.
5. **გადაუღეთ მკაფიო სქრინშოტი ამ საბოლოო გვერდს** (ან გამოიყენეთ ღილაკი `🖨️ ბეჭდვა / PDF შენახვა`) და ატვირთეთ დავალების ჩაბარების სისტემაში.
