## 🎯 მიზანი და ფორმატი

ტრადიციული, მშრალი ტესტებისგან განსხვავებით, ეს ტესტი აგებულია **12 რეალისტურ საინჟინრო ქეისზე** (Real-world Production Cases):
- დეველოპერი აწყდება ბაგს პროდაქშენზე ან DevTools-ში;
- აანალიზებს გაფუჭებულ კოდს, ზომების მათემატიკას ან სელექტორის მახეს;
- პოულობს არა ზედაპირულ პატჩს, არამედ პრობლემის ნამდვილ ძირეულ საინჟინრო მიზეზს (Root Cause).

ტესტი არის **საშუალო სირთულის (Mid-Level)** — არც ელემენტარული და არც ხელოვნურად გადატვირთული.
